# SeedGrid

Minecraft Java seed map. Companion Fabric mod: [seedgrid-marks](https://github.com/offjext/seedgrid-marks).

Author: Exempler201

## App

[Releases](https://github.com/offjext/SeedGrid/releases): `SeedGrid-1.0.1-win.exe`

From source:

```
npm install
npx electron .
```

`start.bat` or `npm run pack`.

## Show at game

Fabric Loader + Fabric API, jar from [seedgrid-marks](https://github.com/offjext/seedgrid-marks/releases) into `.minecraft/mods`. Start Minecraft, then SeedGrid. Click a marker, **Show at game**.

Key **K**, `/seedgrid list`, `/seedgrid clear`, `/seedgrid size`.
