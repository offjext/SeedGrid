# SeedGrid Marks

Fabric mod for [SeedGrid](https://github.com/offjext/SeedGrid). **Show at game** puts a mark in Minecraft.

| Minecraft | Jar |
| --- | --- |
| 26.2 | seedgrid-1.0.0+26.2.jar |
| 26.1 | seedgrid-1.0.0+26.1.jar |
| 1.21.11 | seedgrid-1.0.0+1.21.11.jar |
| 1.21.1 | seedgrid-1.0.0+1.21.1.jar |

Fabric Loader + Fabric API. Jar into `.minecraft/mods`. Start the game, then SeedGrid.

**K** mark list. `/seedgrid list`, `/seedgrid clear`, `/seedgrid size`.

Build: `gradlew.bat build`. New Minecraft version: PORTING.md.
